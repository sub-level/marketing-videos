# public/sfx

One-shot sound effects (whoosh, whip, click, ding, page-turn) go here. Pull
from an attribution-free pack such as `@remotion/sfx`, or from a subscription
library such as Epidemic Sound for the richer motion-graphic swooshes, morphs
and UI confirms, and mirror the files locally so headless renders never depend
on the network.

Keep variants of the same sample as their own files with the measurement in the
name or a comment: `whoosh-tight.wav` is `whoosh.wav` with 0.30s trimmed off its
head so its peak lands about six frames after it fires, which is what a hard cut
wants. See `.claude/skills/video-audio-stack/SKILL.md`.
