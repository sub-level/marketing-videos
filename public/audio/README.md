# public/audio

Music beds go here. Nothing ships with the repo: most produced tracks are not
licensed for redistribution, so bring your own and verify it with ffmpeg before
cutting to it (see `.claude/skills/video-audio-stack/SKILL.md`).

The films in this repo's showcase are scored with **Epidemic Sound** tracks. A
subscription covers marketing videos and ads while it is active, and it ships an
MCP server so the agent can search and audition the catalog itself. Config and
caveats are in the audio skill.

**Record what you used.** Next to every file here, keep a line with the track
title and artist:

```
bed-main.wav    "Track Title" by Artist Name (Epidemic Sound), 34.6s
```

Six months later that is unanswerable from the waveform, and you need it for
re-licensing and for the platform's rights screens. Keep the files themselves out
of git.
